## أوامر acp الموحّدة

```
# طلبات المراسلة
acp                        ← عرض الطلبات المعلقة
acp قبول <GID>             ← قبول طلب مراسلة
acp رفض  <GID>             ← رفض طلب مراسلة

# طلبات الصداقة
acp صديق                   ← عرض الطلبات (مع ترقيم)
acp صديق قبول كل           ← قبول الكل
acp صديق رفض  كل           ← رفض الكل
acp صديق قبول 1            ← قبول الأول في القائمة
acp صديق قبول <UID>        ← قبول بـ ID مباشر

# قائمة الأصدقاء
acp أصدقاء                 ← عرض قائمة أصدقاء البوت
acp أصدقاء حذف <UID>       ← حذف صديق
```

## أوامر stats الموحّدة

```
stats                      ← إحصاءات المجموعة الحالية
stats global               ← إحصاءات البوت الكلية
stats info                 ← معلومات المجموعة التفصيلية
```
