# 🛡️ أوامر الإدارة — src/commands/admin

## الأوامر الجديدة (مضافة في هذه النسخة)

| الأمر | البديل العربي | الدور | الوصف | يعتمد على FCA |
|---|---|---|---|---|
| `admin` | `مشرف` / `ترقية` | مشرف مجموعة | ترقية/تخفيض عضو | `api.changeAdminStatus` |
| `rename` | `اسم` / `سمي` | مشرف مجموعة | تغيير اسم المجموعة | `api.setTitle` |
| `nickname` | `لقب` / `nick` | مشرف مجموعة | تغيير لقب عضو | `api.changeNickname` |
| `mute` | `كتم` / `صامت` | مشرف مجموعة | كتم الإشعارات | `api.muteThread` |
| `emoji` | `ايموجي` / `رمز` | مشرف مجموعة | تغيير إيموجي المجموعة | `api.setThreadEmoji` |
| `color` | `لون` / `اللون` | مشرف مجموعة | تغيير لون المجموعة | `api.setThreadColor` |
| `poll` | `تصويت` / `استفتاء` | مشرف مجموعة | إنشاء تصويت | `api.createPoll` |
| `pinmsg` | `تثبيت` | مشرف مجموعة | تثبيت رسالة | `api.pinMessage` |
| `threadinfo` | `معلومات_المجموعة` | الجميع | معلومات المجموعة | `api.getThreadInfo` |
| `members` | `أعضاء` | الجميع | قائمة الأعضاء مع تمييز المشرفين | `api.getThreadInfo` + `api.getUserInfo` |
| `archive` | `أرشفة` | مطوّر | أرشفة/إلغاء أرشفة محادثة | `api.changeArchivedStatus` |
| `unfriend` | `حذف_صديق` | مطوّر | حذف مستخدم من الأصدقاء | `api.unfriend` |
| `friendreq` | `صداقة` | مطوّر | إدارة طلبات الصداقة | `api.handleFriendRequest` |
| `broadcast` | `بث` / `رسالة_جماعية` | مطوّر | رسالة جماعية لكل المجموعات | `api.getThreadList` |
| `leave` | `مغادرة` / `خروج` | مطوّر | إخراج البوت من المجموعة | `api.removeUserFromGroup` |

## الأوامر الموجودة (مُحسَّنة)

| الأمر | ما تغيّر |
|---|---|
| `kick` / `طرد` | دعم طرد متعدد (منشن أكثر من شخص في نفس الوقت) |
| `acp` / `طلبات` | إعادة كتابة كاملة — أصغر بـ 60% مع نفس المزايا |
| `acp صديق قائمة` | عرض طلبات الصداقة المعلقة مباشرةً |

## أدوار المستخدمين

```
role: 0 → مشرف مجموعة (يُتحقق داخلياً بـ isGroupAdmin)
role: 1 → مشرف بوت (moderator)
role: 2 → مطوّر (developer)
```

## أمثلة الاستخدام

```
# ترقية مشرف
.مشرف @أحمد

# تغيير اسم المجموعة
.اسم مجموعة البرمجة العربية

# تغيير لقب عضو
.لقب @أحمد الكابتن

# إنشاء تصويت
.تصويت ما أفضل وقت؟ | صباح | مساء | ليل

# كتم المجموعة ليوم
.كتم يوم

# طرد أشخاص متعددين
.طرد @أحمد @خالد

# عرض معلومات المجموعة
.معلومات_المجموعة

# قائمة الأعضاء (صفحة 2)
.أعضاء 2

# أرشفة المحادثة
.أرشفة

# قبول طلب مراسلة
.acp قبول 123456789

# قبول طلب صداقة
.acp صديق قبول 100012345678

# بث رسالة (تجريبي)
.بث تجريبي أهلاً بالجميع!
```

## ملاحظات

- أوامر `nickname` و `mute` و `emoji` و `color` و `pinmsg` و `poll` تتطلب **MQTT متصل**
- أمر `broadcast` يُرسل بمعدل رسالة كل **2 ثانية** لتجنب قيود فيسبوك
- أمر `leave` يعمل عبر `removeUserFromGroup` لأن فيسبوك لا يدعم "leave" مباشرةً في Messenger API
